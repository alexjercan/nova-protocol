# Retro

- The flake was cross-beat state leakage, not slow rendering or random guidance.
- Scenario replacement is a better chapter boundary than a list of combat
  entities to clean manually. Ownership handles future transient types too.
- Assert exact fixture cardinality at phase boundaries. "At least one torpedo"
  allowed a degraded salvo to look successful.
- Keep screenshot staging explicit. Injected production-path damage is valid
  when the image is the contract and the step does not claim emergent balance.
- Add a generic autopilot chapter API only after another example proves the same
  stable sequence.
