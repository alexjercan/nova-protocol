Crafting: second slice, consumables

Task 20261116-132140. Design for review, 2026-11-17. Code map with paths and lines: MAP-2.md in this folder. Slice 1 (recipes, craft job, Craft view) is landed in c876b6454, 969f17601, 7e53f8721. Nothing in this page is built.

Recommendation in one block. Three consumables, each one hold item that the ship makes from ore or parts on a Ship recipe:
  • Repair kit (key 1): 80 HP over 10 s to the most damaged live sections. Fixes section loss in a fight.
  • Boost cell (key 2): x1.5 thrust for 8 s in manual flight. Gets a hurt ship out of a fight or home.
  • Decoy flare (key 3): re-aims every torpedo homing on you, from 400 to 3000 m, at a point 800 m off your ship. It needs no running state. It is the cut line: drop it first if the slice runs long.
A new content kind Consumable makes an item usable and names one effect from a closed enum. Keys 1, 2 and 3 are new rebindable FLIGHT actions. The Inventory pane gets a Use verb. Timed effects run on the game clock and are saved. Stations stock the three items, and start kits carry some. Plus two content-only part recipes so a lost docking port can be rebuilt in the field from ore. No AI change.

2. The three consumables

ItemKeyEffectRefused (item kept)

Boost cell BoostCell2Every thruster impulse x1.5 for 8 s while no autopilot verb flies. The clock runs while an autopilot verb flies, but the factor is not applied then. none in hold; a boost runs; docked; no live thruster

Stacking: one running effect per type. Different types run together (kit and boost at once). A Use of a running type is refused, not extended, so a double press never wastes an item.

3. Activation UX

Recommend: one FLIGHT action per effect type, keyboard 1, 2, 3, rebindable in Settings > Controls > FLIGHT. Gamepad unbound by default (no pad button is free in flight, crates/nova_ship/src/input/bindings.rs:36-39). Plus a Use verb on own rows in the Inventory pane.
  • Digits are free in flight; no base or example content maps one; keycap glyphs exist (crates/nova_hud/src/key_glyphs.rs:87-97). A flight action joins flight_rig_reserved_sources (bindings.rs:152-171), so a mod ship that maps a section to 1, 2 or 3 fails lint.
  • Labels: use_repair_kit "Use Repair Kit", use_boost "Use Boost Cell", use_flare "Use Decoy Flare".
  • Inventory pane: InventoryActionType::Use on an own row whose item has a Consumable. One click uses one. It runs the same plan function as the key. Under TAB the clock is held, so a used kit starts healing when the pane closes. No new bar, no new button: one chip on the row, as Jettison is.
  • No hotbar, no slot assignment. The keybind dock shows a chip per consumable the hold carries (see HUD).

4. Content format and lint

Recommend: a new content kind Consumable, one entry per usable item, keyed by the item id. It is additive: no existing item or mod changes shape. Every field is required.
Consumable((
    item: "RepairKit",
    effect: Repair((health: 80.0, duration_secs: 10.0)),
)),
Consumable((
    item: "BoostCell",
    effect: ThrustBoost((factor: 1.5, duration_secs: 8.0)),
)),
Consumable((
    item: "DecoyFlare",
    effect: Flare((near_m: 400.0, far_m: 3000.0, lure_m: 800.0)),
)),

Lint (content lint and the load merge, keyed by the item id)

  • Unknown item. The item is an ItemRoleType id (engine code already spends those; a usable PdcRound would fight the reload).
  • health, duration_secs not finite or not above 0; duration_secs above 60.
  • factor not in (1.0, 3.0].
  • near_m not above 0; far_m not above near_m; lure_m not above the largest torpedo blast_radius in the merged catalog (300 m in base), so a lure can never sit inside a blast that reaches the ship.
  • Two consumables with the same effect type in the merged catalog (each type has one key). An overlay of the same item replaces it, as a recipe overlay does.

6. Runtime effects

pub struct ShipConsumableEffects(pub Vec<RunningConsumable>);  // Component on the ship root
pub struct RunningConsumable {    // serde, deny_unknown_fields
    pub item: ItemDesignId,       // a Repair or ThrustBoost consumable
    pub elapsed_secs: f32,        // 0 <= elapsed < duration_secs
}
  • Use: a ConsumableUseRequest { ship, effect type } from the key or the pane. plan_consumable_use (pure, nova_gameplay) checks the refusals in the table above. On a pass it removes one item from ShipInventory, then pushes a running entry (Repair, ThrustBoost) or re-aims torpedoes (Flare). The item is taken at use, unlike jobs: the effect starts at once, and there is no Cancel.
  • Clock: Update on Res<Time>, set ConsumableSystems after CraftJobSystems (both are on the root; state the order). TAB and pause hold it, as they hold every job.
  • Repair tick: health * dt / duration_secs this frame, given to the lowest-share live, enabled section with health above 0 (the plate job's section filter, repair_jobs.rs:486-488), carried to the next section at max. A pure split function holds the rule.
  • Boost: thruster_impulse_system multiplies the impulse by the root's boost factor (thruster_section.rs:620) when the root has no Autopilot. The autopilot plan reads the unboosted magnitude (flight/autopilot.rs:499) and never sees the factor. The signature reads the magnitude too (signature.rs:111-140), so a boost does not raise it. No speed cap exists to adjust.
  • Flare: for each torpedo with TorpedoTargetEntity equal to the ship root and a hostile owner, in the band: remove TorpedoTargetEntity and set TorpedoTargetPosition to the lure point. That is the state a torpedo enters when its target dies (projectile.rs:25-38); it flies there and fuzes at half blast radius (projectile.rs:294-299). Run it .before(update_target_position). The lure point: ship + 800 m * normalize(approach x ship_up), with ship_right when the cross product is near zero. TorpedoTargetChosen stays, so PDCs keep it as a target (assignment.rs:205).
  • Docked: boost refused. Kit allowed (the station also sells plates). Flare allowed but rarely useful.
  • Hull buy or board: running effects are removed with the jobs (spaceship.rs:880-887).

AI

No AI change in this slice. AI ships neither use nor react to consumables. AI torpedo launch logic is unchanged; a flared AI torpedo is lost to its owner, which may fire again. AI use of kits is a later slice.

7. Save

  • FrozenShipState.effects: Vec<RunningConsumable>, required like repairs (spaceship.rs:650-678). Freeze beside the jobs (:1054-1065), restore beside them (:2146-2163).
  • check_saved_jobs (save/mod.rs:1185-1326) refuses: an item with no consumable; a Flare entry; two entries of one type; elapsed_secs not finite, below 0 or at or past the duration.
  • A flared torpedo saves as SavedTorpedoTarget::Frozen(point), which exists (torpedo_section/frozen.rs:89-93). No new torpedo state.
  • Older saves: the new kind and items change the catalog digest, so a save of another catalog is refused at the header (merge.rs:980-1020), as slice 1 decided. No exception.

9. Supply: stock and start kits

Generated stations stock no raw ore (station_layout.rs:110-122). Unverified: whether trader visits bring ore to a station (station_visits.rs). So a combat role cannot buy the ore for boost cells or flares. Two changes:

  • Station stock: each item that has a Consumable joins the goods budget at weight 1.0, read from GameConsumables (mod consumables are stocked too). The Ammo-category filter at :505 stays role-only.
  • Start kits: bounty_hunter, military, pirate and scavenger add 3 RepairKit and 4 DecoyFlare; industrial and transport add 3 RepairKit and 3 BoostCell. The kit builder takes role ids only today (start_roles.rs:150-176, unverified span), so it takes item ids instead. This also gives the unarmed roles an escape tool (uneven start roles).

10. Forks

Fork 1: content format

  1. Recommend: a Consumable kind keyed by item. Additive, a mod can make a base item usable without replacing it.
  2. A required use: field on every Item. Breaks every mod item (breaking); None on 23 base items.
  3. Engine role items with const numbers. Not moddable; adds three ids to ItemRoleType.

Fork 2: activation

  1. Recommend: one flight action per effect type, keys 1, 2, 3, plus a pane Use verb.
  2. Four slot keys, items assigned to slots in the pane (Everspace 2 style). Saved slot table, more UI.
  3. Pane Use only. Too slow for a flare; TAB holds the clock.

Fork 3: the set

  1. Recommend: kit, boost, flare; the flare is the cut line.
  2. Kit and flare only (both fight fragility).
  3. Kit and boost only (no torpedo code; flare later once AI torpedo use is measured).

Fork 4: supply

  1. Recommend: craft, station stock and start kits.
  2. Craft only. Combat roles get boost cells and flares only by mining or loot.
  3. Station only. No recipes; misses the crafting point.

Fork 5: category

  1. Recommend: existing categories (Repair, Parts, Ammo). The Use chip marks a usable row.
  2. A new Consumable category: one filter chip and a market rule key, but every ItemCategoryType match, icon and color must take it.

Fork 6: boost scope

  1. Recommend: manual flight only (no factor while an autopilot verb flies).
  2. All thrust. Autopilot stops and GOTO legs then run on a thrust they did not plan for. Risk of overshoot.

Fork 7: two consumables of one effect type

  1. Recommend: lint refuses it. One key, one item; lifts when slots (fork 2.2) land.
  2. The key uses the first held one in item-id order. Silent and surprising.

Fork 8: dock-chain part recipes

  1. Recommend: add base/docking_collar and base/actuator_pack now. Content only; it feeds field rebuild of the docking port, the owner's top pain.
  2. Later, with the sections-as-items decision.

Fork 9: kit timing

  1. Recommend: heal over 10 s. Readable on the chip; a burst still beats it.
  2. Instant 80 HP. Simpler; too strong as a panic button.

12. Dies, may break, fails loudly

Dies

  • Doc "There is no fuel category: thrust never consumes stock" (inventory.rs:332-333).
  • Doc "No recipe makes a new item" (recipes.rs:5-7).
  • Doc "a torpedo keeps its first target for life" (torpedo_section/mod.rs:729-737): a flare re-aims it.
  • Role-only start-kit stock signature, if fork 4.1.

May break

  • A mod ship that maps a section to keys 1, 2 or 3 fails lint (breaking for that mod; base and example map none).
  • Generated station stock and start-kit tests (counts change). World generation output changes; older saves are refused by the catalog digest anyway.
  • Fights run longer with kits, so ammo use per fight rises (tasks/20261116-132139/MEASURE.md).
  • Boost at x1.5 on a light hull: unmeasured feel; collision damage at higher speed is the player's choice.
  • Exhaustive Content matches in the editor (compiler finds them).

Fails loudly

  • A consumable with an unknown item, a role item, a bad number, a lure inside the largest blast, or a second of one type: lint error, then load error, keyed by the item id.
  • A save with an unknown or non-timed effect item, a duplicate type or a bad elapsed: the world is refused.
  • A running effect whose item has no consumable at runtime: panic (the save check refuses it first).

14. Research

Short, sourced by a web pass on 2026-11-17. Fandom pages were read through search excerpts only (HTTP 402 on fetch). Old forum posts may not match current game versions.

Patterns that fit Nova

  • Fixed key per slot for fight consumables: Everspace 2 binds devices to 1-4 and consumables to 5-8; Starsector has one ship-system key. An inventory Use is for calm use. Point defense stays automatic, as Nova's PDCs are.
  • Finite items for economy effects, charges for panic buttons. Elite heat sinks and FTL missiles are stock you restock; Starsector flares and Everspace devices regenerate. Nova has no regenerating systems, so items it is.
  • Countermeasures in three layers: kill (PDC; Everspace 2 Missile Defense System), lure (Starsector flares), break lock (Elite ECM; a missile that loses lock flies on to the last known point). Nova's flare is a lure that reuses the break-lock fallback the torpedo already has.
  • Why craft rather than buy: field availability (Elite synthesis, No Man's Sky portable refiner), materials from mining or salvage, and no station in reach. Keep field recipes simple; keep advanced ones at stations (Space Engineers Survival Kit vs Assembler, Minecraft 2x2 vs 3x3, Starbound table upgrades).
  • Field repair has limits so stations stay useful: Elite's AFMU cannot fix the hull and needs ammo; only repair limpets fix the hull in the field, and they cost cargo space. Nova's kit heals but never revives a lost section.
  • Stacking is a stated rule: Elite fires one heat sink per press even with several launchers. Nova refuses a second use of a running type.
  • Running out is recoverable, not a game over: FTL fuel and distress beacon, Starsector CR decay. Nova has SOS.
