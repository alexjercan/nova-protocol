# Accepted visual baseline

Frozen evidence of the first four-page visual PoC, before the dialogue and
location-card revision. The user approved its visual direction, not every
appearance, ship design, or detail as canon.

- `page-01.svg` through `page-04.svg`: original self-contained page renders.
- Matching PNGs: the inspected browser renders of those pages.
- `generate.py.txt`: the original generator preserved as evidence, not another
  maintained or runnable generator.
- `source-sha256.json`: hashes of all seven original PoC files, verified again
  after the byte-for-byte move into the task.

Use `../../comic-opening-poc/` for the working source and latest preview. Do not
regenerate or edit this baseline to match later changes.
