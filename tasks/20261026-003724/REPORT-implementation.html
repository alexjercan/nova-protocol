3. The implemented rule

One owner type carries the rule: CargoCanister in nova_gameplay. Wreck drops, mining and jettison call pack; the intake calls fits_any and take_fitting. Both share one private helper, take_into.

Cap

CARGO_CANISTER_MAX_MASS_G = 1_000_000 (inventory.rs:1236). Was 200,000 g at 112b79a0d. One global value: wreck, mining, jettison, item lint and save check all read it.

Pack

CargoCanister::pack (inventory.rs:1286-1318) fills each canister in item id order with as many whole items as fit under the cap. It skips a stack whose next item is too heavy and goes on. The next canister starts again from the lowest remaining id. It replaces the per-item CargoCanister::split, which the diff deletes.

Take

take_fitting (inventory.rs:1320-1331) moves min(count, floor(room / mass)) of each stack in id order. fits_any (:1334-1339) is true when one whole item fits. Helper: take_into, :1347-1365.

Intake

run_cargo_intakes sets the door from fits_any (cargo_intake_section.rs:606-613). On trigger contact it takes what fits, pushes one PickedUp per stack, and despawns only an emptied canister (:628-659). Module rule: :35-40.

destroyed body
  -> wreck_cargo::drop_wreck_cargo        one drop = hold + collapse salvage
  -> CargoCanister::pack(stacks)          wreck_cargo.rs:137
  -> MinedCanisterQueue::leaving          wreck_cargo.rs:138-139, FIFO, id minted at birth

  -> run_cargo_intakes                    contact + fits_any -> take_fitting
       -> ShipInventory::add + PickedUp { canister: id, item, count }
       -> despawn only when is_empty()

A six-section ship with a hold of 25 iron ore, 300 PDC rounds and 3 hull plates collapses. Each section adds floor(0.3 x count) of its parts to the root's salvage, so the root leaves one drop. 5. Claim 2: partial take keeps the canister id asserted

Test sections::cargo_intake_section::tests::a_canister_heavier_than_the_free_room_gives_up_the_whole_items_that_fit (cargo_intake_section/tests.rs:514-581). The fixture ship has a 400 kg hold stocked with 38 hull plates (380 kg), so 20 kg is free. One 4-plate canister (40 kg) drifts with its centre half a capture gap in front of the intake face. The test runs the real physics trigger and the real run_cargo_intakes system. It replaces the deleted test a_canister_larger_than_the_free_room_is_refused_whole, which asserted the old whole-fit refusal.

Arithmetic: 400 - 380 = 20 kg free; floor(20 / 10) = 2 plates; 4 - 2 = 2 left (20 kg); 2 + 2 = 4 plates taken over two takes, 38 + 2 = 40 and 38 + 2 = 40 plates held after each take. Log line: ... gives_up_the_whole_items_that_fit ... ok, 1 passed; 0 failed (log 02, section 1).

11. Blast radius

  • Every canister producer. The cap is global. Mining, jettison and wreck drops now make canisters up to five times heavier and fewer of them. A mined or jettisoned canister of one item can now be up to 1,000 kg; a hold under that size still takes part of it.
  • Intake semantics. A canister can now be taken in several passes. PickedUp / onpickedup fires per take, so one canister id can appear in more than one take (nova_events/src/lib.rs:1016-1022). A mod or audit that assumed one report set per canister must change.
  • Door. The door now opens when one whole item fits, not when the whole canister fits.
  • Saves. The save check now allows up to 1,000 kg per canister, so a save written at 112b79a0d (at most 200 kg per canister) still passes it. A build at 112b79a0d refuses a save from this tree that holds a canister over 200 kg. No save migration is part of the change.
  • Content and docs. Generated base RON (intake description, pickup lesson text), CHANGELOG, wiki, creator docs and a web widget change with the code. The generated RON came from the Rust builders in the diff; regeneration was not re-run in this evidence set.
  • Removed path. CargoCanister::split is deleted; the whole-fit intake check at 112b79a0d (free_g >= total_mass_g) is gone. No compatibility path remains.
  • Not changed. Strip yield, reach, trigger shape, drop count per wreck, recipes and item masses. Separate section drops stay separate.
