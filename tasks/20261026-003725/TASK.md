## Delivered: MATCH velocity slice (implemented 2026-11-04, committed 2026-11-05)
- `AutopilotAction::MatchTarget { target }` (`flight/state.rs`), stepped by `match_target_step` (`flight/autopilot.rs`): each tick asks the RCS for the whole relative velocity to the target root's `LinearVelocity`; `rcs_burn_system` clamps and pays it. Engines spool dark; the rotation command holds where the pilot left it, so attitude and roll hold.
- Chord: `on_autopilot_stop_input` reads the RCS modifier's held state (not `RcsActive`), so a withheld RCS still refuses instead of braking. The RCS modifier action now spawns ahead of STOP, so a one-frame Shift+X enters RCS first and keeps the MATCH. Side effect: every same-frame Shift+key now acts as Shift first, then the key. Shift+G/Shift+O engage (or re-engage) GOTO/ORBIT under RCS, and Shift+[ / Shift+] trim RCS up/down instead of stepping the component lock. Before, the key acted first.
- Implementation decisions (smallest behavior consistent with STOP and the neutralized RCS brake). The owner accepted the slice in game on 2026-11-05 as shipped; a later change to these is a new decision:
  - Completes at relative speed <= 0.5 m/s (`MATCH_RELEASE_SPEED`): one tenth of the 5 m/s capture gate, above one tick of the 11 m/s^2 measured tidal pull. No hold after the match.
  - Velocity reference is the target root COM velocity (the capture gate's), not the point velocity `v + omega x r`.
  - Target captured at the press, like GOTO. Ends on target gone (`TARGET LOST`), lost flight computer (`NO FLIGHT COMPUTER`), RCS capability off (`NO RCS`), empty magazine (`RCS EMPTY`). Completes at once when the target is docked to the hull: the two roots of a spinning pair differ by the spin, and a match that kept flying drained the magazine (reproduced in `match_on_a_docked_target_completes_without_a_push` before the fix). No main-drive fallback and no gravity gate: a pull the RCS cannot beat drains the magazine and ends it.
  - Cancels: Shift+X again, Z, fresh burn press, bound thruster key, a fresh Shift press, plain X (STOP takes over), tap-clear of the travel lock (any travel lock, as for GOTO). Mouse and wheel while Shift stays held are ignored, not breakouts. A re-designated lock or a lock dropped behind cover does not change or end the MATCH: it keeps the target from the press.
  - Gates: STOP withheld, docked without the helm and lock on the docked partner are silent no-ops, as for STOP. Refusals post a HUD notice (`MatchRefusal` message): `NO TARGET`, `NO RCS`, `RCS EMPTY`.
  - Status: mode chip `AP MATCH - BURN`. In this commit the dock's STOP chip is inverted while a MATCH flies (`maneuver_chip` maps `MatchTarget` to the STOP chip). A separate UI pass, uncommitted at closure and not part of this task, changes the dock: the chip reads STOP with the RCS modifier up and MATCH only while it is held, and is inverted only while its own word flies. No new capability, binding row or telemetry field. The chord follows both existing rows, so the pad gets left-stick-click (hold) + East.
  - Save: additive `SavedAutopilotAction::MatchTarget { target: SavedTargetRef }`; a missing target fails the load like a GOTO target. Not breaking.
- Tests: `shift_x_matches_the_travel_lock_and_never_stops`, `shift_x_refuses_with_a_notice_and_never_stops` (`input/player/flight_rig.rs`); `flight/tests/match_target.rs` (`match_brings_the_relative_speed_to_zero_on_the_rcs_alone`, `match_on_an_empty_magazine_disengages_without_the_drive`, `match_ends_when_its_target_is_gone`, `match_without_a_flight_computer_ends_with_a_refusal`, `match_on_a_docked_target_completes_without_a_push`); save round trip extended (`a_load_restores_a_stop_an_orbit_a_held_velocity_and_a_match`).
