## Story

Replace placeholder picker textures with reproducible stills from the same
automated showcase runs used for web assets and regression evidence. Each
scenario thumbnail must have a declared producer and remain legible at the
picker's 320x180 presentation size.

## Steps

- [ ] Inventory every picker-visible scenario and its current thumbnail source.
- [ ] Add a declared 16:9 capture checkpoint for every placeholder-backed
      scenario. Prefer existing showcase runs; add a scenario-specific producer
      only when no representative run loads that content.
- [ ] Derive deterministic 320x180 PNGs into the owning base/mod asset tree and
      register source, checkpoint, destination, and dimensions in the shared
      capture manifest.
- [ ] Update Rust content builders and hand-authored mod content as appropriate;
      run `cargo run -p nova_assets --bin content -- gen` for generated base RON.
- [ ] Add a picker harness assertion that every visible thumbnail resolves and
      no listed scenario uses the known placeholder paths.
- [ ] Capture the picker itself and inspect crop, contrast, and subject clarity
      at the real details-pane size.

## Definition of Done

- Every picker-visible scenario has a representative, non-placeholder image.
  (test: `scenario_picker_thumbnails_resolve_without_placeholders`)
- Each thumbnail is generated by one declared showcase checkpoint at 320x180.
  (cmd: `nix develop --command python3 scripts/gen-web-screenshots.py --check`)
- Generated base scenario RON matches its Rust builders.
  (test: `content_ron_parity`)
- The owner accepts all thumbnail crops in the rendered picker.
  (manual: inspect the Scenarios picker capture at its shipped layout size)
