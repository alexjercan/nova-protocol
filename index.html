What you do in Nova Protocol

Build it, fly it, and break it. Every visual below comes from the same sections, physics, weapons, and damage simulation you play.

01

Build the ship you can see

Choose parts from a visual gallery, mate real sockets, and preview derived cladding around the build before it leaves the editor.

02

Fly the hull you built

Manual flight and GOTO use the same mass, controller, and thrusters. Watch the ship swing, burn, flip, and settle instead of sliding along an invisible path.

03

Fight through geometry

Kinetic rounds punch, Pierce rounds rake through layers, Serpents weave, and each point-defence mount chooses a threat it can actually reach.

04

Ships wear every hit

Cracks deepen over wounded plating. Machinery sparks. Outer sections sever into wreckage, and a beaten hull peels apart while its surviving guns keep firing.

05

Read the cockpit

The contextual HUD surfaces only what the current maneuver needs. NOVA OS opens the same live ship as a map, status schematic, and command terminal.
